## About

**Mini-Game-Tech** brings the spirit of classic arcade games to modern desktops and the web. The organization maintains a growing collection of game remakes, a web-based arcade, and an Android companion application.

Projects range from lightweight Python games to feature-rich C# experiences. Each repository has its own setup instructions, technology choices, and project policies—check its README before you get started.

## The arcade

Play and explore the game collection on the [Mini-Game-Tech website](https://minigame-tech.github.io/minigame-tech.github.io/). Availability and supported downloads may vary by game; the website is the best place to find the current player-facing experience.

| Project | What it is | Technology |
| :--- | :--- | :---: |
| [Frogger](https://github.com/Mini-Game-Tech/Frogger) | A Python remake of the classic road-and-river arcade game. | Python |
| [PacMan](https://github.com/Mini-Game-Tech/PacMan) | A Python take on the maze-chase classic. | Python |
| [Space-Invaders](https://github.com/Mini-Game-Tech/Space-Invaders) | A C# remake of the iconic alien-shooter arcade game. | C# / .NET |
| [Tetris](https://github.com/Mini-Game-Tech/Tetris) | A modern C# take on the falling-block puzzle game. | C# / .NET |
| [Web arcade](https://github.com/Mini-Game-Tech/minigame-tech.github.io) | The web platform and game catalog, hosted with GitHub Pages. | HTML |
| [Android app](https://github.com/Mini-Game-Tech/App-Android) | An Android companion for the web arcade. | Java |

## Built with

- **Game development:** Python and C# / .NET
- **Graphics and audio:** Pygame, g2d, and Raylib-cs, depending on the project
- **Web:** HTML, CSS, and JavaScript
- **Mobile:** Java and Android WebView
- **Publishing:** GitHub Pages and project-specific desktop builds

## Getting started

1. Browse the [repositories](https://github.com/orgs/Mini-Game-Tech/repositories) and choose a project.
2. Read its README for prerequisites, controls, supported platforms, and run instructions.
3. For the quickest way to play, visit the [web arcade](https://minigame-tech.github.io/minigame-tech.github.io/).

Build requirements and platform support differ between projects. Refer to each repository for the authoritative details.

## Contributing and project policies

The organization includes projects with different contribution models and licenses. Some repositories welcome pull requests; others may be intended for personal or educational use. Before contributing, redistributing, or reusing code or assets, review the relevant repository’s `CONTRIBUTING.md`, `LICENSE`, and other policy files.

For feedback or to report a problem, open an issue in the repository for the affected project, if issues are enabled there.
